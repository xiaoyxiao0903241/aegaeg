# 代码注释约定

> 语言：**简体中文**。内容：**只写最终结论**。新代码与触及文件必须遵守；禁止为统一格式批量翻写无关存量。

## 格式

| 位置            | 形式                    | 示例                                              |
| --------------- | ----------------------- | ------------------------------------------------- |
| 文件 / 导出符号 | `/** 一句结论。 */`     | `/** 同 path 在飞或 unknown 闩锁时视为 busy。 */` |
| 字段 / 参数     | 同行或上一行 `/** … */` | `/** 历史参数名；传入 `isLocked`（busy）。 */`    |
| 行内            | `// 一句结论。`         | `// onSuccess 失败不得推翻写成功。`               |
| 分节            | `// —— 域 ——`           | `// —— 钱包 / 兑换 ——`                            |

一句为宜；需要两条不变量时最多两短句，仍只陈述现行规则。

## MUST

- 中文叙述；合约名、函数名、路径、`WRITE_PATH` 等标识符保持英文原文。
- 写**现行**行为、不变量、禁令（「须…」「禁…」「仅…」）。
- JSDoc 标签（`@deprecated` 等）保留英文标签名，说明用中文。

## MUST NOT

- 英文全文注释（本约定生效后的新写 / 触及面）。
- 设计稿、ticket、评审、中途方案、对比过程（「先 A 后改 B」「临时」「原本想…」）。
- 复述下一行代码字面（`// 返回 true`）。
- 过时词冒充现状（如注释仍写 soft gates，而代码已是 block-reason）。

## 存量

未触及的英文或中英混排注释不在本切片强制改写。触及某文件时，将该文件内**改到的注释**一并收成中文结论体。

## Import 排序

`eslint-plugin-simple-import-sort`：`simple-import-sort/imports` + `exports` 为 **error**（进 `lint:src` / `pnpm check`）。分组：side-effect → `node:` → 外部包 → `~/` → 相对路径。自动修：`pnpm exec eslint src --fix`。
