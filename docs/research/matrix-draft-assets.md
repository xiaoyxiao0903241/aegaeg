### `claimable_gagx` 语义（本轮钉死）

| 层                                               | 口径                                                                                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| API `POST /assets/reward-summary.claimable_gagx` | `DAO READY（贡献 cap）+ 释放池 releasing_amount + 涡轮 unclaimed_total`（见 api.md / openapi）                                                         |
