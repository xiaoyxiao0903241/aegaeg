> 审计产物（FE 接线修复后持续维护现存问题）。  
> 初版：2026-08-07 · 同日多次合并补充；**B 表现存仅未修项**

> **布局/文案硬约束：** 需修复项只改数字取数与接线；**禁止**加删布局块、加删改用户可见文案。

## 裁决优先级

1. **BSC 链上 view / 交易语义**（最高）
2. 手册（与链冲突 → 记表 A ❌，FE **跟链**）
3. API（与链冲突 → 记表 A ❌/⚔️，FE **跟链**）
4. Figma / i18n（稿有控件 → UI 保留；**措辞/单位与链冲突 → 冲突表，不进需修复**）

**编号：** `A-01`… / `B-01`… / `C-01`…（冲突表沿用 C 号）稳定；关闭/迁出不复用。

**冲突表准入：** 设计取舍，或「改数也无法让现有稿面措辞变真 / 产品确认设计如此」。
